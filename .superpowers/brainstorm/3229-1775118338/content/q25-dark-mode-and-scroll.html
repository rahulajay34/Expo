Chatbox — Theming, Scroll Behavior & Conversation Switch

Questions 25–27: Visual polish and navigation feel

Q25: How should the chat look in dark mode?

Your app already supports light/dark/system themes

A

Match Existing Theme Exactly

Use the same CSS variables from your design system. User messages get a slightly lighter surface, AI messages use the card background. Borders, text colors all from existing tokens. Zero new colors.

B

Elevated Contrast

Slightly more contrast than the rest of the app for readability during long chat sessions. Brighter text, slightly deeper background. Chat-specific dark mode overrides. Better for extended reading.

C

True Black Option

An extra "AMOLED" dark mode in settings for pure black backgrounds (#000). Battery-friendly on OLED screens. Chat bubbles float on black. Striking but polarizing.

Q26: How should auto-scroll during streaming work?

When AI is streaming a response, the chat needs to scroll down

A

Smart Auto-Scroll

Auto-scrolls while streaming ONLY if user is already near the bottom (~100px). If user scrolled up to read older messages, scrolling pauses — they're reading. The scroll-to-bottom FAB appears with a "streaming..." indicator.

B

Always Follow

Always auto-scroll to the latest token. Simple behavior. If user scrolls up, auto-scroll resumes on next token. FAB button to jump back if needed.

C

Sticky with Manual Override

Auto-scroll is on by default. If user scrolls up, a "⏸ Auto-scroll paused" pill appears. Click it or scroll to bottom to resume. Explicit state so user always knows what's happening.

Q27: How should switching between conversations feel?

Clicking a different conversation in the sidebar list

A

Instant Swap

Click conversation → messages instantly replace. No transition. Scroll position jumps to bottom. Fast and snappy. Like switching tabs.

B

Quick Crossfade

150ms fade out → fade in. Subtle enough to feel smooth but fast enough to not feel slow. Messages fade in with a gentle stagger (first 5 visible messages). Scroll starts at bottom.

C

Directional Slide

If switching to a newer conversation, content slides left. Older conversation, slides right. Gives spatial sense of timeline. 200ms transition. Like swiping through pages.
