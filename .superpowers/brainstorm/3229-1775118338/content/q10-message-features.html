Chatbox — Message Interactions & UX

Questions 10–12: What users can do with individual messages

Q10: What actions should be available on individual messages?

Hover actions / context menu on each message bubble

A

Copy to Clipboard

One-click copy of the message text. For AI responses, copies the raw markdown. Toast confirmation "Copied!"

B

Regenerate Response

Re-run the AI response for the same prompt. Replaces the current response. Useful when the answer isn't great.

C

Edit & Resend (User Messages)

Edit a previously sent message and resend it. The conversation continues from that point, discarding messages after it.

D

Save to Content Library

Save an AI response directly to your Content Library as a new content item. Great for preserving useful answers.

E

Copy Code Blocks Separately

Each code block in AI responses gets its own copy button in the top-right corner. Language label shown. One-click copy.

Q11: How should the "New Chat" experience work?

What users see when starting a fresh conversation

A

Clean Empty State

Just the input bar with a centered greeting. "How can I help you today?" Minimal and fast. Focus goes straight to the input field.

B

Suggestion Cards

4-6 clickable suggestion cards above the input: "Explain a concept", "Help me write", "Solve a problem", "Generate quiz questions". Cards disappear after first message.

C

Branded Welcome + Suggestions

App logo/icon centered, "New-S13n Chat" heading, brief capability description, then 4 suggestion cards. More personality, slightly heavier.

Q12: Should the chat have any system prompt / persona configuration?

Can users customize HOW the AI responds?

A

Fixed System Prompt

One hardcoded system prompt that makes the AI helpful and educational. Users don't see or change it. Simplest approach.

B

Preset Personas

Choose from 3-5 built-in personas: "Tutor", "Study Buddy", "Researcher", "Creative Writer", "Code Helper". Each adjusts tone and behavior. Selectable per conversation.

C

Custom Instructions

A "Custom Instructions" field in settings where users write their own system prompt. Plus the presets from B as starting points. Full control for power users.
