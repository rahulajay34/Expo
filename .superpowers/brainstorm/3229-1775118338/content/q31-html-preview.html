HTML Live Preview — Clarifications

3 quick questions to nail down the preview feature

Q31: How should the HTML preview render?

When the AI generates HTML, how does the user see it?

A

Inline Sandboxed iframe

HTML renders in a sandboxed iframe right inside the chat message. Resizable height. "View Code" toggle to switch between rendered preview and source. All within the message bubble.

B

Side Panel Preview

Chat stays on the left, a preview panel opens on the right when HTML is detected. Code in the chat, live render beside it. Like a built-in CodePen. Panel closeable when not needed.

C

Full-Screen Preview Modal

"Preview" button on HTML code blocks. Clicking opens a near-full-screen modal with the rendered page. Tabs for Desktop/Tablet/Mobile viewport sizes. Close to return to chat. Maximum preview space.

D

Inline Thumbnail + Expand to Full

Small inline preview (~300px tall) in the message showing a live thumbnail of the rendered HTML. Click to expand into a full-screen modal with viewport switcher. Best of both: quick glance + deep inspection.

Q32: What editing capabilities for the generated HTML?

Can users tweak the code, or just view/copy?

A

View & Copy Only

User sees the code + preview. Can copy the full HTML. To make changes, they ask the AI: "change the header color to blue". AI regenerates. Chat-driven iteration.

B

Live Editable Code

The code block becomes an editable textarea. User tweaks HTML/CSS directly, preview updates in real-time. Like a mini CodePen. Then can ask AI to "continue from here" with the edited version.

C

Copy + "Refine This" Button

Copy button for the code. Plus a "Refine" button that pre-fills the chat input with "Update this HTML:" and attaches the current code as context. User adds their tweak request and sends. Keeps it conversational.

Q33: Should the preview support external resources?

CDN links, Google Fonts, Tailwind CDN, images, etc.

A

Full External Access

The iframe can load CDN scripts (Tailwind, Bootstrap, GSAP), Google Fonts, Unsplash images, etc. Full web page capability. The AI can generate realistic, styled pages with real assets.

B

Whitelisted CDNs Only

Allow specific trusted CDNs: cdnjs, unpkg, Google Fonts, Unsplash. Block everything else for security. Covers 95% of use cases without opening up to arbitrary scripts.

C

Self-Contained Only

No external requests. All CSS must be inline or in <style> tags. No CDN. Keeps it simple and secure, but limits what the AI can generate. Good for basic layouts.
