Chatbox — Files, Save-to-Library & Keyboard

Questions 22–24: Attachment handling, library integration, and shortcuts

Q22: How should file attachments work in the chat?

You want file/image attachments — let's define the flow

A

Inline Preview Chips

Attached files appear as small chips above the input bar (filename + size + ✕ to remove). Images show a tiny thumbnail. Click to preview full-size in a modal. Files sent as base64 in the message payload.

B

Rich Preview Cards

Attached files appear as cards below the input: images show a larger preview, PDFs show first-page thumbnail, text files show first few lines. Drag to reorder multiple files. More visual but takes more space.

C

Minimal Badge

Just a "📎 2 files" badge next to the send button. Click to see/manage attachments in a small popover. Keeps the input area clean. Files are secondary to the text message.

Q23: When saving an AI response to Content Library, what format?

You want "Save to Library" — how should the saved content look?

A

Raw Response

Save the AI message exactly as-is. Title auto-generated from first line or AI summary. Tagged as "Chat Export" type. Preserves markdown, code blocks, everything verbatim.

B

Formatted with Metadata

Save with a header block: title, date, source conversation link, user's original question. Then the AI response below. More context when reviewing later in the library.

C

Quick Save Modal

A small modal pops up: edit the title, pick a content type (Lecture/Note/Reference), optionally trim the content. Then save. Takes 3 seconds but gives user control over how it's catalogued.

Q24: Should the chat have keyboard shortcuts?

Your app already has a "?" shortcut modal — should chat extend it?

A

Essential Only

Enter → Send
Shift+Enter → New line
Esc → Stop generation
That's it. Three shortcuts, zero learning curve.

B

Extended Set

Essentials from A, plus:
Ctrl/⌘+N → New chat
Ctrl/⌘+↑ → Edit last message
Ctrl/⌘+Shift+C → Copy last response
Ctrl/⌘+E → Toggle thinking
Added to the existing "?" shortcuts modal.

C

No Shortcuts Beyond Enter/Shift+Enter

Keep it mouse/touch first. No keyboard shortcuts to learn. The input field handles Enter/Shift+Enter naturally. Everything else through buttons.
