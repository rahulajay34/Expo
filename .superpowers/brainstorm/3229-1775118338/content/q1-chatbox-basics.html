Advanced Chatbox — 3 Foundational Questions

Let's nail down the core concept before diving into details

Q1: Where should the chatbox live in the app?

This defines how users discover and interact with the chat

A

Slide-out Side Panel

A panel that slides in from the right (like your existing Notification Centre). User can keep working while chatting. Overlays content partially.

B

Dedicated Full Page (/chat)

A new route in the sidebar nav, like Content Library or Settings. Full-screen chat experience with its own layout. Most space for conversations.

C

Floating Chat Bubble

A persistent bubble in the bottom-right corner that expands into a chat window. Always accessible from any page. Like Intercom/Crisp style.

D

Hybrid: Nav Page + Floating Mini-mode

Full page at /chat for deep conversations, PLUS a minimizable floating widget so users can keep chatting while on other pages.

Q2: What's the primary purpose of this chatbox?

This shapes the entire feature set and API integration

A

Content Assistant

Help users refine generated content — ask "make this section more engaging", "add more examples to chunk 3", "rewrite for a younger audience". Context-aware of their generated materials.

B

General-Purpose AI Chat

A standalone ChatGPT-like experience within the app. Users can ask anything — homework help, brainstorming, explanations, coding questions. Not tied to generated content.

C

Both: Context-Aware + General

Defaults to general chat, but can "attach" generated content as context. Toggle between free chat and content-aware mode. Best of both worlds.

Q3: How should conversations be managed?

Single thread vs. multiple conversations

A

Single Active Thread

One conversation at a time. Simple UI, no thread management. "New Chat" clears and starts fresh. Like a basic chatbot.

B

Multi-Conversation with History

Multiple saved conversations in a sidebar list. Search, rename, delete conversations. Like ChatGPT's conversation list. Stored in localStorage.

C

Auto-Organized Threads

Conversations auto-group by topic or by the content they reference. No manual management needed. AI auto-titles each thread. Smart cleanup of old threads.
