Chatbox — Thinking Display, Errors & Empty States

Questions 19–21: Edge cases and polish

Q19: How should the "thinking" display work in chat?

You want thinking visible — let's define the UX

A

Inline Collapsible Above Response

Thinking appears as a collapsible block directly above the AI response. Starts expanded while streaming, auto-collapses when response begins. Click to expand/collapse anytime. Subtle violet/grey styling.

B

Side Drawer

A small "🧠 Thinking..." pill appears on the message. Click it to open a right-side drawer showing the full chain-of-thought. Keeps the chat clean but thinking accessible.

C

Global Toggle + Inline

A toggle in the chat header: "Show thinking". When ON, thinking blocks appear inline (like A). When OFF, completely hidden. User controls verbosity globally. Remembers preference in localStorage.

Q20: How should errors and failures be handled in chat?

Network drops, API errors, rate limits during conversation

A

Inline Error Message + Retry

Error appears as a red-tinted message bubble in the chat flow: "Something went wrong. [Retry]" button right there. Keeps context visible. Auto-retry on network recovery.

B

Toast + Retry in Input Bar

Error toast slides in at top. Input bar shows "Failed to send — [Retry] [Edit]". The failed message stays in chat with a ⚠️ indicator. Less intrusive.

C

Silent Auto-Retry + Fallback

Automatically retries 3 times with backoff (like your existing client.ts). Only shows error if all retries fail. Then inline error with manual retry. User barely notices transient failures.

Q21: What should the conversation list look like when empty (first-time user)?

The very first time someone opens /chat

A

Minimal: Just "New Chat" Button

Empty sidebar with a single "New Chat" button and subtle text: "Your conversations will appear here." Clean, no distraction. The chat area itself has your animated welcome.

B

Mini Onboarding

3-step quick intro cards in the sidebar: "1. Start a conversation → 2. Ask anything → 3. Save useful answers". Dismissible, never shows again. Helps new users understand the feature.

C

Ghost Conversations

Show 2-3 faded "example" conversations with titles like "What is quantum computing?" that the user can click to start a real chat with that prompt. Disappear once user creates their first real conversation.
