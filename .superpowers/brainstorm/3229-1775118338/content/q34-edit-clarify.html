HTML Editing — Quick Clarification

Question 34: You said "kind of but not full control" — which feels right?

A

"Refine This" Button (Chat-Driven)

No code editing. A "Refine" button pre-fills the input with context. User types "make the header bigger" and AI regenerates the full HTML. All iteration happens through conversation. Simple, no code editor needed.

B

Minor Edits in Preview Modal

In the full-screen preview, a small "Edit" toggle reveals the source code in a read-friendly view. User can make small tweaks (change a color, fix text) and see live updates. But major changes go through chat. Best of both.

C

Click-to-Highlight + Chat Refine

In the preview, user can click any element to highlight it. Then a "Change this" button pre-fills chat with: "Update the [highlighted element]:" User describes what they want. AI surgically updates just that part. Visual + conversational.
