Chatbox — API, Models & Power Features

Questions 16–18: The engine under the hood

Q16: Which AI model/API should power the chat?

You're currently using Minimax via /api/minimax for content generation

A

Same Minimax API

Reuse your existing /api/minimax route and streaming client. Zero new infrastructure. Same model, same costs. Simplest to implement — just wire up the existing client to the chat UI.

B

Separate Chat API Route

New /api/chat route that still hits Minimax but with chat-specific config — different system prompt, different temperature, different max tokens. Keeps generation and chat concerns separate.

C

Multi-Model Support

Let users pick from multiple models (Minimax, GPT-4, Claude, Gemini). Model selector in chat header. Each model gets its own API route. Power user feature but more complex.

Q17: How should the chat handle long conversations and context limits?

Models have token limits — what happens when a conversation gets really long?

A

Silent Sliding Window

Keep the system prompt + last N messages (e.g., 20). Older messages silently drop from context. User doesn't notice unless they reference something old. Simple and automatic.

B

Auto-Summarize Old Context

When hitting ~70% of token limit, automatically summarize older messages into a condensed context block. Preserves key information while freeing tokens. Slightly slower on long chats.

C

Warn + Suggest New Chat

Show a subtle banner when context is getting full: "This conversation is getting long. Start a new chat for best results." User decides when to start fresh. Transparent approach.

Q18: Any power features you want in the chat?

Pick the extras that excite you (multi-select)

A

LaTeX / Math Rendering

Render mathematical equations beautifully using KaTeX. AI wraps math in $...$ or $$...$$. Essential for STEM conversations.

B

Syntax-Highlighted Code Blocks

Full syntax highlighting for 50+ languages using highlight.js (already in your app). Language auto-detection. Copy button per block.

C

Rendered Tables

Markdown tables render as proper styled HTML tables. Sortable columns. Clean borders matching your design system.

D

Mermaid Diagrams

AI can generate flowcharts, sequence diagrams, class diagrams etc. Rendered inline using Mermaid.js (already lazy-loaded in your app).

E

Keyboard Shortcuts

Ctrl+N new chat, Ctrl+↑ edit last message, Ctrl+Shift+C copy last response, Esc to stop generation. Power user velocity.

F

Scroll-to-Bottom FAB

Floating "↓" button appears when scrolled up. Shows unread message count badge. Click to smooth-scroll to latest. Auto-hides when at bottom.
