Chatbox — Tone Modes, Animations & Mobile

Questions 13–15: Personality, motion design, and responsiveness

Q13: Here are tone mode ideas — which set feels right?

A toggle/dropdown in the chat header to switch response style

A

Minimal Set (4 modes)

Straight → Short, direct, no fluff
Detailed → Thorough explanations with examples
Friendly → Warm, encouraging, empathetic
Raw → Blunt, no sugar-coating, tell it like it is

B

Extended Set (6 modes)

Concise → Shortest possible answer
Balanced → Default, medium detail
Deep Dive → Exhaustive, professor-level
ELI5 → Explain like I'm 5
Empathetic → Patient, encouraging, kind
No BS → Blunt, raw, zero fluff

C

Slider Spectrum (no discrete modes)

Two sliders instead of modes:
Length: Concise ←→ Detailed
Tone: Blunt ←→ Friendly
Users dial in exactly what they want. More flexible, slightly more complex UI.

Q14: What animation style for the chat experience?

Your app already has rich animations — how should chat messages move?

A

Subtle & Smooth

Messages fade-in + slide up gently (200ms ease-out). Typing indicator pulses softly. No dramatic effects. Professional and clean. Matches your existing Notion-like aesthetic.

B

Playful Spring Physics

Messages pop in with a slight spring/bounce (overshoot then settle). User messages slide from right, AI from left. Typing indicator has bouncing dots. Conversation list items stagger-animate on load.

C

Rich Micro-interactions

Everything in B, PLUS: hover glow on messages, smooth scroll-to-bottom with momentum, code blocks slide-expand when they appear, thinking section accordion with spring, copy button checkmark morph animation, conversation switch crossfade.

Q15: How should the chat behave on mobile?

Your app already has a bottom nav on mobile — how does /chat integrate?

A

Simple: Full-screen Chat Only

On mobile, /chat shows just the chat area. Conversation list accessible via a back arrow / hamburger. No split view. Input bar fixed at bottom above the keyboard. Standard mobile chat app pattern.

B

Swipe Drawer for Conversations

Same as A, but swipe right from the left edge to reveal conversation list as an overlay drawer. Swipe back to close. Feels native and gesture-friendly. iOS/Android standard pattern.

C

Tab-based: Chats List + Active Chat

Two sub-tabs within /chat: "Chats" (list) and active conversation. Tap a conversation to switch to chat tab. Like iMessage/WhatsApp navigation pattern.
