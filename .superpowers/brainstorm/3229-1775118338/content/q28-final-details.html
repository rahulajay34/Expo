Chatbox — Final Details

Questions 28–30: Last decisions before we design

Q28: What should the chat input area look like?

The composer bar at the bottom — the thing users interact with most

A

Clean Single-Line (Auto-Expanding)

Single line by default, grows up to ~5 lines as user types. Send button on the right. Attachment icon on the left. Minimal border, rounded corners. Focuses on the text. Like iMessage.

B

Input + Mini Toolbar

Auto-expanding textarea with a small toolbar row below it: attach file, code block insert, and send. Toolbar only appears on focus, hides when empty and blurred. Keeps extra tools accessible but unobtrusive.

C

Floating Card Composer

Input lives in a slightly elevated card with subtle shadow, detached from the page edges by 12-16px margin. Feels like a floating dock. Attach + send inside the card. More visual presence.

Q29: How should the conversation sidebar header work?

The top of the left panel — new chat button, search, etc.

A

Clean: Title + New Chat Button

"Chats" heading on the left, "+" icon button on the right. That's it. New chat creates and selects immediately. Clean and functional.

B

Search Bar + New Chat

Search input at top that filters conversations by title. New chat button below or beside it. Good when conversation count grows. But you said no search needed earlier.

C

Branded Header

Small app icon + "S13n Chat" text, with a "New Chat" button styled as a primary pill button. Feels like a product within a product. Gives the chat its own identity.

Q30: What's the overall vibe you want when someone opens /chat?

The gut feeling — pick the one that resonates

A

"Sharp Tool"

Feels like opening a professional instrument. Clean, precise, no wasted space. Monochrome with one accent color. Like Linear or Raycast. The UI disappears and the conversation is everything.

B

"Warm Workspace"

Feels inviting and comfortable. Soft corners, gentle spacing, warm neutral tones. Like Notion or Arc browser. You want to spend time here. Professional but not cold.

C

"Modern & Confident"

Feels like a well-designed product that knows what it is. Bold typography, clear hierarchy, intentional whitespace. Not flashy, not minimal — just right. Like Vercel or Stripe dashboard. Confidence in every pixel.
