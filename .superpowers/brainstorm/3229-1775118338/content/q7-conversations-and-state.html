Chatbox — Conversations, State & Storage

Questions 7–9: How data flows and persists

Q7: How should the conversation sidebar be organized?

You chose multi-conversation + auto-organized. Let's define the grouping.

A

Time-Based Groups

Today, Yesterday, Previous 7 Days, Previous 30 Days, Older. Auto-titled by AI from first message. Simple, predictable, like ChatGPT.

B

Smart Categories + Time

AI auto-tags conversations into categories (Math, Science, Writing, Coding, etc.) shown as collapsible sections. Within each, sorted by recency. Pinned conversations at top.

C

Flat List with Search & Filters

All conversations in a single chronological list. Powerful search bar at top. Filter chips (All, Starred, Archived). No grouping — rely on search instead.

Q8: What conversation actions should users have?

Right-click / three-dot menu options per conversation

A

Rename

Override the auto-generated title with a custom name. Inline editing right in the sidebar.

B

Pin / Star

Pin important conversations to the top of the list. Starred section always visible above time groups.

C

Export

Export conversation as Markdown, PDF, or JSON. Download the full thread with formatting preserved.

D

Archive

Hide from main list without deleting. Separate "Archived" section accessible via filter. Reduces clutter.

E

Delete

Permanently remove with confirmation dialog. Option to "Delete all" for bulk cleanup.

F

Branch / Fork

Create a new conversation branching from a specific message. "What if I asked this differently?" Conversation tree exploration.

Q9: localStorage is limited to ~5MB. How should we handle storage?

Chat history can grow fast — what's the strategy?

A

Simple with Auto-Cleanup

Store everything in localStorage. When approaching 80% capacity, auto-archive oldest conversations. Show storage gauge in settings. Clear warning before data loss.

B

IndexedDB for Scale

Use IndexedDB instead of localStorage — supports hundreds of MBs. Conversations stored as structured objects. Much more room. Still fully client-side, no server needed.

C

Hybrid: IndexedDB + Export Reminders

IndexedDB for active storage. Periodic reminders to export/backup old conversations. Storage stats visible in chat settings. Manual cleanup tools.
